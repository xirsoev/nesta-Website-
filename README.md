# NESTA

Каталог недвижимости на PHP и MySQL.

## Развёртывание на существующем хостинге

1. Сделайте резервную копию сайта и базы данных.
2. Распакуйте архив `nesta-filemanager-upload.zip` в корень сайта. Архив намеренно не содержит `config/`, чтобы сохранить параметры подключения к MySQL на хостинге.
3. Импортируйте `database-add-homes.sql` через phpMyAdmin, выбрав существующую базу NESTA. Скрипт добавляет обезличенные карточки и обновляет только шесть исходных демонстрационных записей с совпадающими исходными адресами; аккаунты и избранное он не меняет. Повторный запуск не создаёт копии новых карточек.

## Новые объекты и приватность

Параметры 12 домов кратко пересказаны по публичным объявлениям Яндекс Недвижимости в Приморском крае: https://realty.yandex.ru/primorskiy_kray/kupit/dom/. Точные адреса, имена, телефоны и другие контакты продавцов не копируются. Фотографии на сайте иллюстративные, цены и наличие могут измениться; посетителям показывается предупреждение с источником.

## Локальный запуск

Настройте локальное подключение к MySQL в `config/config.php`, создайте базу и импортируйте `database.sql`, затем `database-add-homes.sql`. Затем запустите PHP-сервер из корня проекта, например: `php -S 127.0.0.1:8124`.
